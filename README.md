# Harsh Portfolio — Full-Stack Software Engineer & Systems Architect

An award-winning 3D spatial web portfolio built with **React 19**, **Three.js**, **TypeScript**, and **Tailwind CSS v4**.

---

## 🚀 Quickstart & Development

### 1. Run Development Server
```bash
bun install
bun run dev --port 3000
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 2. Build for Production
```bash
bun run build
```
Generates a minified, tree-shaken, zero-defect bundle in `dist/`.

---

## ⚓ Architectural Highlights

- **Interactive 3D WebGL Ocean Canvas:** Gerstner wave displacement equations, moonlit specular reflection, and smooth inertia scroll.
- **Spotlight Specular Cursor Tracking:** Real-time mouse coordinate physics casting 24k gold light flares over technology cards.
- **Interactive 3D Spatial Tilt:** Real-time perspective transforms on the hero card and captain portrait (`perspective(1000px) rotateX/rotateY`).
- **Web Audio Haptics:** Procedural ocean ambient soundscape and tactile click feedback with mute toggle.
- **Zero AI Slop:** No fake progress bars, no fake benchmark terminals, no clichéd template patterns.
- **100% Fully Responsive:** Pixel-perfect from 375px mobile to 4K ultra-wide with 0ms CLS.
