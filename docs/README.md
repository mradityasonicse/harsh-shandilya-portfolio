# ⚓ The Developer's Pearl — 3D Pirate Portfolio
A Pirates-of-the-Caribbean-inspired 3D portfolio website. The visitor embarks on a voyage: a ship sails across a dark ocean, each portfolio section is a "port of call" on the map.

## Concept
- **Hero:** 3D galleon (Black Pearl style) sailing on a moonlit burning-sunset ocean
- **Sections:** Styled as aged parchment / treasure maps / captain's log
- **Scroll = Voyage:** Camera moves through 3D scenes along the ship's journey
- **Atmosphere:** Blood-red accents, ember particles, fog, torn-paper UI

## Tech Stack
- Next.js / Vite + React 19 + TypeScript
- Three.js WebGL (procedural ocean shaders, buoyancy physics, rising ember particles, moon halo)
- Tailwind CSS + Lucide Icons + Canvas Confetti
- Procedural Web Audio API soundscape (ocean surf, sea breeze, creaking timber)
- Responsive 60-120 FPS GPU transforms with 0ms CLS

## Legal Note
Theme is inspired by the nautical pirate aesthetic (dark sea, parchment, pirates). Do NOT use official movie logos, posters, fonts (Blackpearl), or music. Uses original and CC0 assets only.
